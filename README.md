# Shoutr

Shoutr is the voice-typing app on this Linux machine. Hold Ctrl and Space, speak, and let go. The words show up in the hub, stay on the clipboard, and land in the text box you were using.

## Speaking

Hold Ctrl+Space while you talk. Letting go ends the recording.

The transcript appears in the hub. Shoutr pastes it into the focused text box and leaves the same text on the clipboard, so you can paste it again yourself.

You can hold the shortcut inside a text box. The Space key stays with the shortcut, and the document keeps the text you already had.

If the microphone is muted, the toast that says so can be clicked.

Dictation leaves the keyboard in the text box. The hub does not take it. Opening Shoutr from the tray brings the hub forward when you want it.

## The hub

The window is named Shoutr. You can move it and minimize it.

The panel menu opens the hub. The first-run screen and Settings use the Shoutr name. The account already stored on this machine is the one that opens, with the history and settings that belong to it. The words you speak are transcribed under that account.

## The app in front

Shoutr names the app you are typing in. When that app shares the cursor, such as a terminal or an ordinary text field, the words on either side of the cursor go with the dictation. The Cursor editor, and some Firefox pages, still get the pasted words, without that surrounding text.

## Look

The hub is navy, with blue actions and a coral-to-amber glow while you are recording. The sidebar and the tray use the waveform mark. Menu labels are light on the navy, so they stay easy to read.
