# Project context

Shoutr is a personal learning project: a narrow Linux dictation client built by studying Wispr Flow. Another machine installs that build with `./install.sh`.

- The work is strictly for personal education.
- It is not a commercial product and not a public program.
- The private GitHub repo is `13pixlar/shoutr`. Do not make that repository public and do not publish the vendor files, extracted trees, or a repacked build.

Prefer clear, teachable code and explanations.

Shoutr v1 opens the hub on About Shoutr. It keeps dictation, the dictionary, insights, and settings. Linux patches turn off meetings, promos, auto-update, and extra pre-warmed windows.

Always read ROADMAP.md at the start of a session. The **Current status** section there is the hand-off: what is done, what to do next, and the constraints that still apply.
